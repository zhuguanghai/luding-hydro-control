# 泸定水电站智慧化上下游水情控制系统

四川华电泸定水电有限公司 · 大渡河干流第 12 级 · 二等工程/大Ⅱ型

泄洪闸开关作业 · 高效 · 精准 · 智能化管理（演示仿真版，内置数据引擎驱动）

## 功能总览

- **登录页**：三级角色权限（超级管理员 / 管理员 / 普通操作员），演示账号一键登录
- **监控大屏**：实时水情总览、水位占比雷达、流域三维联动（拖拽旋转 / 滚轮缩放 / 水流粒子速度∝流量 / 降雨动画联动雨强 / 站点标牌 1 秒刷新）、24h 水位·流量曲线、泄洪闸卡片、AI 闸位操作建议、实时告警跑马灯、机组运行状态、未来 24h 来水预测、闸位调整 24h 水位推演
- **管理后台**
  - 2.1 传感器数据采集：24 个传感器台账（在线/离线/故障统计、分区筛选、实时曲线、导出台账）
  - 2.2 泄洪闸位优化：五种操作工况（水位稳定 / 发电量最大 / 下泄变幅最小 / 操作次数最少 / 闸门流量均衡）、AI 推荐开度、人工干预滑杆（单次步长 ≤0.5m）、弧门开度-过流特性曲线 Q=μ·b·e·√(2gH)、24h 库水位推演、AI 决策依据留存、六项安全约束校核
  - 2.3 气象数据：流域网格化气象（9×9km）、240h 预报（前 90h 逐时 / 90-144h 逐 3h / 144-240h 逐 6h）、40 天逐日预报、逐时段明细
  - 2.4 来水预测：LD-RF v2.3（LSTM+XGBoost 残差校正）、24h 逐时 + 10 天逐日含置信区间、对照 GB/T 22482 的精度评估（RMSE/MAPE/合格率）
  - 2.5 发电优化调度：调度目标权重、日内平均出力/发电量/水能利用率/弃水量、机组最优组合（并网/解列演示）、日内逐小时仿真 + 未来 10 天逐日节点推演、调度约束校核
  - 2.6 后台管理：用户管理（新增/冻结/重置密码/角色）、内容管理、数据管理（导入/导出/备份）、行为监测（操作留痕）、外部系统对接（RESTful / Modbus 网关 / 正向隔离穿透模板）、系统设置（阈值参数实时生效并持久化）

## 技术栈

React 19 + TypeScript + Vite + Tailwind CSS + Recharts + React Router（Hash 路由）

- `src/engine/sim.ts`：内置仿真数据引擎（每 1s 推进：水位演进、弧门过流、机组出力、AI 闸位推荐、气象/来水/调度推演），全局发布订阅驱动全站联动
- `src/engine/auth.ts`：账号与角色权限（演示环境存于浏览器 localStorage）
- `src/components/BasinCanvas.tsx`：伪三维等距投影流域可视化（Canvas 60fps）

## 本地运行

```bash
npm install
npm run dev      # 开发
npm run build    # 生产构建（dist/）
npm run preview  # 预览构建产物
```
